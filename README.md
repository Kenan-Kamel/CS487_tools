# CS 487: AI for Security — Lecture & Lab Materials

Slide deck and hands-on lab stations for the **AI as a Security Teammate**
lecture in CS 487 (Building Secure Computer Systems) at UIC.

Students see how LLMs fit inside real security tools — fuzzing, reverse
engineering, vulnerability detection — then try it themselves.

## Quick start

### 1. Build the slides

Requires [Node.js](https://nodejs.org/) (for `npx`) and `python3` with
`matplotlib` (for figures).

```bash
# Generate the SVG figures
pip install matplotlib
python3 slides/figures/make_figures.py

# Build the HTML deck (add --no-pdf to skip the PDF)
bash build.sh
```

Open `slides/cs487-ai-security-teammate.html` in Chrome. Press **f** for
full-screen, **p** for presenter view.

### 2. Set up Claude Code

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Hand out a class API key:

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # one key per class, revoked after
claude
```

### 3. Install Ghidra

Install [Ghidra 12.1.4](https://github.com/NationalSecurityAgency/ghidra/releases).
Optionally add [GhidraMCP](https://github.com/LaurieWired/GhidraMCP) for agentic
analysis with Claude Code (not required — the fallback is exporting decompiled C
and pasting it into claude.ai).

## Lab stations

No API key required. Paste decompiled code into claude.ai or ChatGPT.

**Run the full live demo:** `bash lab/demo.sh`

### Station 1 — Heartbleed (CVE-2014-0160) (`lab/station3-ghidra/heartbleed/`)

Reverse-engineer a stripped binary that reproduces the Heartbleed vulnerability.
The LLM identifies the missing bounds check that lets a client leak server memory.

```bash
cd lab/station3-ghidra/heartbleed
make                        # builds and strips ./heartbleed
python3 trigger.py          # creates malicious input
./heartbleed trigger.bin | xxd | head -30   # see the leaked secrets
```

Import `heartbleed` into Ghidra, export the decompiled C, paste it into an LLM
and ask it to find vulnerabilities.

### Station 2 — Keycheck backdoor (`lab/station3-ghidra/`)

Reverse-engineer a stripped license-key checker. The LLM identifies the FNV-1a
hash algorithm and discovers a hard-coded backdoor key.

```bash
cd lab/station3-ghidra
make                        # builds and strips ./keycheck
python3 findkey.py          # brute-forces a valid key
```

Import `keycheck` into Ghidra and ask the LLM to explain the validation logic
and find any alternate acceptance paths.
